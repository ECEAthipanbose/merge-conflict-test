# Merge Conflict Test Repo

This repository is set up to demonstrate and test merge conflicts.

## Structure

- `app.py` - Main application logic (updated with logger support)
- `utils.py` - Utility helpers (format_output, clamp)
- `logger.py` - Simple logging module
